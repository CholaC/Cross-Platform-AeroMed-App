Functional Requirements
1. The system shall allow health professionals to request specific specialists to visit during scheduled outreach visits and to specify their position in the queue and the date of the outreach visit via a USSD short code 2575 (the ZFDS toll-free number). 
2. The system shall allow health professionals to get SMS and push notifications through the mobile and web applications of approved outreach visits, changes, and cancellations.
3. The system shall support calculation and comparison of eligible air and road transport legs, including distance and estimated travel times.
4. The system shall allow flight operations and dispatchers to assign available transport resources and teams; identify conflicts; approve schedules.
5. The system shall simulate operational factors and decide which factors best predicts outreach schedule efficiency using machine learning modelling.
